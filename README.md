# Reality Director

[体验《旧照相馆封档风波》](https://daizhouchen.github.io/reality-director-demo/) · [阅读产品案例](https://daizhouchen.github.io/demo/reality-director.html)

一个可完整走通的双角色互动短篇：读线索、选择如何表达、碰头对照、作出判断、回看并下载本次复盘。

支持独自预览双角色，或两人共用一台设备轮流阅读。当前为本机预设故事，没有远程联机、实时 AI、定位或支付；进度只保存在当前浏览器，可在首页清除。

`gh-pages` 分支承载静态构建产物，使用相对资源路径。完整产品设计与源工程单独维护。
