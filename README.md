# Reality Director · 城市秘密行动

[选择一场行动](https://daizhouchen.github.io/reality-director-demo/) · [阅读产品案例](https://daizhouchen.github.io/demo/reality-director.html)

在虚构街区中观察原始材料，提出推测，沿不同路线调查，用实际取得的两条凭据留下自己的版本。

- 独行《旧渡口停航风波》：核对调度与维修记录，区分计划、执行和停航经过。
- 双人《旧照相馆封档风波》：同设备私有阅读，选择完整原件或去来源摘要共享，再共同核验。
- 路线带来不同记录，来源选择影响可引用的凭据，结果指出支持范围与缺口；可返回补查、暂停恢复、下载手记或清除本机记录。

当前为预设虚构故事与规则，没有真实路线导航、实时 AI、远程联机或支付。记录只存当前浏览器，故事档案不对外发送。同设备遮挡用于阅读辅助，不提供独立账号安全隔离。

`gh-pages` 仅承载静态构建产物，包含本地依赖与生成的虚构场景图片。完整产品设计与源工程单独维护。
